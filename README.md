# Personal-Schedule-Builder
A personal schedule builder that will sort assignments and commitments into a daily time blocked schedule.

## The Problem
I am trying to solve time management and balance my schedule. I have clubs, classes, exams, and assignments, and struggle to figure out when to start working/studying. I am trying to figure out how to build a study plan that fits into my schedule.

## How It Works
A Java command line tool that takes an input of my classes, clubs, exams, and due dates; it then runs the data through various methods to produce a daily schedule telling me what to work on and when, based on what time I have available and estimated time needed for assignments and studying.

## Tech Stack
Language: Java, HTML

## Usage
Type in correct input for assignments, classes, etc. If input is correct, program will output a schedule

EX: What classes do you have?:
[CS 193]
When does it start?:
[630]
How many hours is it?:
[1]
What homework do you have?:
[Calc HW 19]
How many hours will it take?:
[2]
(input for other classes, homework, etc)

Here is your schedule for the week!:

12:30: Do Calc HW 19
1: Do Calc HW 19
.
